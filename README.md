# Antibody-Antigen ΔΔG Prediction

This repository provides code for predicting changes in binding affinity (ΔΔG) upon point mutations to antibody or antigen sequences, using regression models built on top of pretrained protein language models.

## Installation

```bash
conda env create -f environment.yml
```

## Datasets

We use the synthetic ddG dataset created by Hummer et al. (2025), which was generated by running Rosetta Flex ddG on 1302 antibody-antigen complexes from SabDab with 16 mutants per complex for a total of 20,829 variants. The synthetic ddG labels for each mutant complex can be downloaded from [https://github.com/oxpig/Graphinity/tree/main/data/ddg_synthetic/Flex_ddG](https://github.com/oxpig/Graphinity/tree/main/data/ddg_synthetic/Flex_ddG).

The associated PDB files were extracted from the `synthetic_flexddg_ddg_wt_pdbs.tar.gz` file in [https://doi.org/10.5281/zenodo.15384945](https://doi.org/10.5281/zenodo.15384945).

### Dataset Preparation

Extract the antibody heavy chain, antibody light chain, and antigen sequences from the PDB files. This script creates a JSON file where each key is a chain in each mutant complex with the following data: 
 - `sequence`: The amino acid sequence of the chain
 - `mutation_index`: The position in the sequence where a mutation occurs (only included for mutated chains)

```bash
python scripts/convert_pdb_to_fasta.py \
    --pdb_dir ddg_synthetic/Flex_ddG/flexddg_wt_pdbs \
    --save_path ddg_synthetic/Flex_ddG/flexddg_wt_pdbs.json
```

Read from the JSON file and create a CSV file combining the ddG labels and the 2 antibody chain and 1 antigen chain sequences. If the complex only contains 1 antibody chain, the empty string is stored in the second antibody chain.

```bash
python scripts/build_flexddg_dataset.py \
    --json_path ddg_synthetic/Flex_ddG/flexddg_wt_pdbs.json \
    --ddg_path ddg_synthetic/Flex_ddG/Synthetic_FlexddG_ddG_20829.csv \
    --save_path ddg_synthetic/Flex_ddG/Synthetic_FlexddG_ddG_20829_with_sequences.csv
```

Create train/val/test splits based on sequence similarity thresholds (70%, 90%, 100%, or None) borrowing from the sequence similarity analysis done in Hummer et al. (2025). 

```bash
python scripts/split_train_test.py 
```

## PLM Embeddings and Contact Maps

Use the ESM2 protein language model to embed the sequences of the antibody H chain, antibody L chain, and the antigen chain. Optionally generate predicted contact maps from ESM embeddings.

```bash
python scripts/esm_embedding.py \
    --save_path ddg_synthetic/Flex_ddG/embeddings/embeddings_flexddg.pt \
    --sequences_path ddg_synthetic/Flex_ddG/          Synthetic_FlexddG_ddG_20829_with_sequences.csv   \
    --seqeuence_type "joined_chains" #join H/L/antigen chains with glyceine linkers, use "separate chains" to embed the chains separately \
    --output_type "embeddings" #use "contact_maps" for contact maps \
    --average_embeddings #include this flag to take the average over residue embeddings to produce a single embedding per sequence \
    --mutate #include this flag to also mutate and embed mutated sequences
```

## Zero-shot ΔΔG prediction 

As a baseline, we considered two zero shot ΔΔG prediction methods. First, we compute likelihood ratios from the ESM model of mutated to wildtype residues and look for correlations with ΔΔG labels. Second, we correlated the norm of the difference between the mutated and WT residue embeddings from ESM with ΔΔG labels.

```bash
python scripts/zero_shot_esm_ddg.py \
    --sequence_type "joined_chains" \
    --method "likelihood ratio" | "embedding_diff" \
    --data_path "ddg_synthetic/Flex_ddG/Synthetic_FlexddG_ddG_20829_with_sequences.csv"
    --embedding_wt_path "path/to/torch_file_embeddings_joined_chains_wt_res.pt" \
    --embedding_mut_path "path/to/torch_file_embeddings_joined_chains_mutant_res.pt"
```
